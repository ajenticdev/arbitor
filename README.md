# Arbitor: SOC Analyst Dashboard & Analysis Tool

Arbitor is a cross-platform security analysis suite designed for SOC analysts and IT security experts. It facilitates the ingestion, normalization, and analysis of diverse IT logs to streamline incident response, trend visualization, and professional reporting.

Features:
- Multi-Source Ingestion: Native support for Splunk, Palo Alto Networks, Cisco, Windows Event Logs, and Linux Syslog.
- Data Normalization: Unifies disparate log formats into a common schema for cross-source correlation.
- OSINT Integration: Optional diffing of ingested data against OSINT IOCs.
- NIST & CISA Standardized
- Visualization: Generate custom trend data using dynamic graphs and charts.
- Non-Destructive Filtering: Execute complex queries using a layered filtering system that preserves underlying data.
- Professional Reporting: Automated formatting for Executive Summaries (EXSUM), emails, and incident tickets.
- Historical Record: Maintain a persistent, searchable record of all investigations and findings.

Supported Platforms:
- Windows
- Linux
- macOS

Installation:
Download the latest binary for your operating system and execute the file. No external dependencies are required for the core analysis engine.
